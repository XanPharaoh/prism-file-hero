# /database-architect - Database Design & Optimization

$ARGUMENTS

---

## Purpose

Invoke the Database Architect for:
- Schema design and normalization
- Database migrations (Prisma, Drizzle)
- Query optimization
- Indexing strategies
- Data modeling and relationships
- Performance tuning

---

## Usage

```
/database-architect design a schema for [entity/feature]
/database-architect help with [migration/schema issue]
/database-architect optimize [slow query]
/database-architect fix [data model problem]
/database-architect review database structure
```
