# /explorer-agent - Codebase Analysis & Discovery

$ARGUMENTS

---

## Purpose

Invoke the Explorer Agent for:
- Codebase discovery and mapping
- Architectural analysis
- Dependency analysis
- Code quality assessment
- Refactoring planning
- Pattern identification

---

## Usage

```
/explorer-agent explore the [system/module] architecture
/explorer-agent map dependencies in [codebase]
/explorer-agent find [anti-pattern/issue] in code
/explorer-agent analyze [code quality/architecture]
/explorer-agent help me understand [system]
```

---

## Skills

- `codebase-analysis` - Structure, dependencies, patterns
- `architecture-review` - Design patterns, coupling
- `code-quality` - Metrics, anti-patterns
- `dependency-mapping` - Circular deps, impact analysis
- `refactor-planning` - Safe refactoring strategies
