# /product-manager - Product Management

$ARGUMENTS

---

## Purpose

Invoke the Product Manager for:
- User story creation and refinement
- Requirements gathering
- Feature prioritization
- Product roadmapping
- User research
- Success metrics

---

## Usage

```
/product-manager help me write user stories for [feature]
/product-manager prioritize [features/backlog]
/product-manager create roadmap for [product]
/product-manager help with [product decision]
/product-manager analyze [user feedback/data]
```

---

## Skills

- `user-stories` - Format, acceptance criteria
- `requirements-gathering` - Stakeholder interviews
- `prioritization` - MoSCoW, RICE, scoring
- `roadmapping` - Timeline, phases, milestones
- `user-research` - Personas, interviews, analytics
