# /test-engineer - Testing Strategies & Automation

$ARGUMENTS

---

## Purpose

Invoke the Test Engineer agent for:
- Writing unit, integration, and E2E tests
- Test coverage analysis
- TDD implementation
- Debugging failing tests
- Test infrastructure setup

---

## Usage

```
/test-engineer write tests for [file/function]
/test-engineer improve coverage on [target]
/test-engineer debug failing test [test name]
/test-engineer setup playwright for e2e
/test-engineer help with [testing issue]
```

---

## What This Agent Does

✅ **Test Writing** - Unit, integration, E2E tests using Vitest, Jest, Playwright  
✅ **Coverage Analysis** - Identify untested code paths  
✅ **TDD Workflow** - Red-Green-Refactor cycle  
✅ **Debugging** - Root cause analysis for test failures  
✅ **Test Infrastructure** - Jest config, GitHub Actions, CI setup  

---

## Examples

```
/test-engineer write unit tests for the reconciliationService
/test-engineer improve coverage on fnbExtractService.ts
/test-engineer debug why my E2E test is flaky
/test-engineer setup Vitest for integration tests
```
