# /project-planner - Project Planning & Task Breakdown

$ARGUMENTS

---

## Purpose

Invoke the Project Planner for:
- Task breakdown and estimation
- Project roadmap creation
- Milestone planning
- Dependency mapping
- Feasibility analysis
- Resource planning

---

## Usage

```
/project-planner break down [feature/task] into subtasks
/project-planner create a roadmap for [project]
/project-planner plan milestones for [timeline]
/project-planner estimate effort for [task]
/project-planner help me plan [initiative]
```

---

## Skills

- `task-breakdown` - Decomposition, dependencies
- `estimation` - Story points, time estimates
- `roadmap-planning` - Phases, milestones, timeline
- `feasibility-analysis` - Risk, constraints, trade-offs
- `resource-planning` - Team allocation, capacity
