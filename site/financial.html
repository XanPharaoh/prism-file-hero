Five deterministic layers between your numbers and a wrong total.

Reconciliation here is not an AI guess. Each layer is pure arithmetic that recomputes the ledger and refuses to export when a single check fails.

BALANCE RECOMPUTE

Opening to closing, re-added

Each line’s balance is recomputed from the last. If it doesn’t match the bank, the row is flagged before it reaches the sheet.

DEBIT / CREDIT ISOLATION

Never both, never neither

A transaction gets exactly one side, cross-checked against the balance movement.

OUTLIER DETECTION

The R10k sanity net

An amount far outside a row’s context is surfaced for review instead of silently categorised.

DUPLICATE PREVENTION

Same line, counted once

Re-imports and overlapping pages are fingerprinted so a single debit never doubles the expense.

CLOSING PROOF

It will not ship a number it can’t re-derive

The whole ledger must balance from opening to closing before export — the check that makes output filing-grade.
